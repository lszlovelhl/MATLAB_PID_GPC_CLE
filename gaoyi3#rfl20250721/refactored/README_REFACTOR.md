## 2. 默认参数 / 控制律说明（本工程与 gaoyi4 完全相同）

**控制方式**：单回路增量式 PID（无 GPC、无在线辨识反馈到输出）。

**入参 / 出参**：13 元素列向量，顺序固定：

| 位 | 符号 | 含义 |
|---|---|---|
| 1 | sp       | 设定值 |
| 2 | pv       | 过程值 |
| 3 | mv       | 输出（上一时刻） |
| 4 | e0       | 当前误差（现算 e0=sp-pv，不读此位，保留占位） |
| 5 | e1       | 上一次误差 |
| 6 | e2       | 上上次误差 |
| 7 | kp       | 比例增益 |
| 8 | ti       | 积分时间 |
| 9 | td       | 微分时间 |
| 10 | man_on  | 手动/自动标志（原版未使用，保留占位） |
| 11 | ulim    | 输出上限 |
| 12 | llim    | 输出下限 |
| 13 | deadzone| 死区宽度 |

**控制律（逐行保持原版）**：

```
e0 = sp - pv
du = kp * [ (e0 - e1) + e0/ti + td*(e0 - 2*e1 + e2) ]
if abs(pv - sp) <= deadzone   ← 注意：本现场为 <= 语义（宝马工程为 <）
    du = 0
mv = mv + du
if mv >= ulim, mv = ulim
if mv <= llim, mv = llim
e2 = e1; e1 = e0
返回 [sp pv mv e0 e1 e2 kp ti td man_on ulim llim deadzone]'
```

> **死区边界行为差异（必须保留）**：本工程死区判断是 `abs(pv-sp) <= deadzone`，
> 即当 `|pv-sp|` **恰好等于** deadzone 时也冻结输出（du=0）。这是现场按实际
> 工况定下的边界行为，重构版严格保留，未改成 `<`。

## 3. 与原版一致性验证结果（test_verify.py，numpy 等价移植）

本机 MATLAB R2025a 许可过期，禁止运行 .m；已将原版 `pid` 与重构版
`pid_calc_v2` 逐行翻译为 numpy，同输入对比，容差 `1e-9`。

| 用例组 | 用例数 | 结果 | 最大误差 |
|---|---|---|---|
| 1. 正常参数随机输入（ti>0） | 20 | 全部一致 PASS | 0.000e+00 |
| 2a. 死区边界 `abs(pv-sp)==deadzone` → du=0 | 1 | PASS（mv 冻结在原值） | 0.000e+00 |
| 2b. `abs(pv-sp)>deadzone` → du 正常作用 | 1 | PASS | 0.000e+00 |
| 3. 输出限幅（mv 冲出 ulim/llim 被钳位） | 1 | PASS（mv=60 钳在 [10,60]） | 0.000e+00 |
| 4a. ti=0 除零防护 | 1 | PASS（v2 输出有限且限幅内；原版复现除零） | — |
| 4b. ti=-3 除零防护 | 1 | PASS（v2 输出有限） | — |

**随机组整体最大误差：0.000e+00**（远小于容差 1e-9，即逐位一致）。

> 说明：ti=0 用例不与原版比对——原版在 ti=0 时 `1/ti=Inf`（numpy 复现出
> divide-by-zero 告警），输出冲成 Inf/NaN，这正是要修复的隐患；v2 将积分项
> 置 0 后输出有限且落在限幅内。

## 4. 现场参数未改动确认声明

逐项确认（重构**只允许**做参数化注释 / ti<=0 修复 / 长度校验，其余一律不动）：

- [x] **控制律**：增量式 `du = kp*((e0-e1) + e0/ti + td*(e0-2*e1+e2))` 逐行未改。
- [x] **回路结构**：13 元素入参 / 出参向量结构、位序、误差滚动（e2=e1; e1=e0）未改。
- [x] **控制策略**：无 GPC、无在线辨识反馈；man_on 仍为占位未启用——未改。
- [x] **现场参数**：kp/ti/td/ulim/llim/deadzone 等现场整定值一律不写死、不改动，
      仍由调用处传入；v2 不设任何覆盖默认值。
- [x] **死区语义**：严格保留 `abs(pv-sp) <= deadzone` 的 **<=** 边界（含恰等点
      冻结），未改为 `<`。
- [x] **限幅逻辑**：先 `mv=mv+du` 再 `>=ulim` / `<=llim` 双向钳位，顺序与原版一致。

## 5. 原版 → v2 差异摘要

| 项 | 原版 `pid_calc.m` | 重构版 `pid_calc_v2.m` |
|---|---|---|
| 函数名 | `pid` | `pid_calc_v2`（接入时调用处需改名） |
| 输入长度校验 | 无 | 不足 13 元素报错 |
| ti<=0 除零 | `1/ti` → Inf/NaN 隐患 | 积分项置 0 并 `warning`，输出有限 |
| 命名 / 注释 | 无注释、索引裸用 | 变量命名清晰、每行语义注释（UTF-8） |
| 控制律 / 死区(<=) / 限幅 / 误差滚动 | — | **逐行完全一致，未改** |

> 即：**正常参数下（含死区恰等边界）v2 输出与原版逐位一致（误差 0）**；
> 唯一行为差异发生在原版本就会崩的 ti<=0 情形。

## 6. 如何接入现场（替换方式）

原版调用处（`on_timer.m` 等）形如：

```matlab
% 原版（函数名是 pid）
newpara = pid(pidloop(:,1));
```

替换为重构版（函数名改为 `pid_calc_v2`，入参出参不变）：

```matlab
% 重构版：正常参数行为与原版逐位一致；ti<=0 时不再崩
newpara = pid_calc_v2(pidloop(:,1));
```

> 注意：原版文件 `pid_calc.m`（函数名 `pid`）保持原样不动；确认现场无误后
> 再决定是否统一切换。`refactored/` 与原版并列存放，随时可回退。
