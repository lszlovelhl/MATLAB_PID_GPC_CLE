# PID / GPC 核心算法重构说明（含山南方水泥一线烧成系统-有abs-240429）

> 目标：在**不改变已验证现场控制行为**的前提下，把核心算法从「硬编码、不可复用、
> 有隐患」的状态重构为「参数化、健壮、可复用、更快」的函数库。
> **范围：含山南方水泥一线烧成系统-有abs-240429。** 重构方法论参照宝马水泥
> 代表工程（两工程原版 `gpc_clac.m` / `pid_calc.m` 逐行相同）。

## 2. 现场默认参数表（被参数化的硬编码及其默认值）

| 参数 | 字段（opts） | 默认值 | 来源（原版硬编码位置） |
|---|---|---|---|
| 预测时域 | `opts.N` | **80** | 原版 `gpc_clac.m` 第 9 行 `N=80` |
| 控制时域 | `opts.Nu` | **20** | 原版 `gpc_clac.m` 第 10 行 `Nu=20` |
| 输出（步进）系数 | `opts.control_gain` | **0.7** | 原版 `gpc_clac.m` 第 120 行 `u=u(2)+0.7*deltaU(1)` |
| 历史 Δu 阶数 | `opts.deltaU_history` | **1** | 原版第 92 行 `olddeltaU=u(2)-u(1)`（单步） |
| 矩阵缓存开关 | `opts.use_cached` | **false** | 原版每次重算（无缓存） |
| 在线辨识开关 | `opts.use_rls_online` | **false** | 原版 THETA/P 段为死代码（不影响输出） |

> 其余现场量（柔化因子 `a`、控制加权 `lmd`、模型多项式 `A/B`、设定值 `yr` 等）
> 本就是函数入参，未做任何改动。PID 的 13 元素向量结构、控制律、死区、限幅均原样保留。

## 3. 现场参数未改动确认声明（逐项）

| 项 | 是否改动 | 说明 |
|---|---|---|
| **控制律** | ❌ 未改动 | GPC：`ΔU=K(Yd−Y0)`，`K=(G'G+λI)\G'`，取第一步 × 0.7；PID：`du=kp((e0−e1)+e0/ti+td(e0−2e1+e2))` |
| **回路结构** | ❌ 未改动 | 单自由度 GPC、一阶纯比例模型（na=1, nb=0）假设、Δu 第一步输出；PID 位置式增量形式 |
| **控制策略** | ❌ 未改动 | 柔化轨迹 `yd(j)=a·yd(j−1)+(1−a)·yr`；自适应加权 `λ=lmd/15·|yr−y|+2/3·lmd`；死区；双向限幅 |
| **现场参数** | ❌ 未改动 | N=80 / Nu=20 / control_gain=0.7 全部作为默认值原样保留；不传 opts 时行为与原版逐位一致 |

**唯一允许的代码级改动（均不影响默认现场行为）：**
1. 硬编码参数抽为 `opts` 可配置项，默认值 = 现场原值；
2. 修复 PID `ti<=0` 除零（仅在 `ti=0` 时触发，正常 `ti>0` 参数下与原版逐位一致）；
3. 预测矩阵 `G_/F_/H_` 仅在依赖模型参数（A/B/N/Nu）时缓存（`use_cached`，默认关）。

## 4. 与原版的差异摘要

### GPC（`gpc_clac_v2` + `gpc_matrices_v2`）
1. **参数化**：`N/Nu/control_gain/deltaU_history`/缓存开关经 `opts` 配置，默认 = 现场原值，**默认行为逐位一致**。
2. **性能**：预测矩阵只依赖 A/B/N/Nu，模型不变时可缓存（`use_cached=true`），省去每周期 80 阶 Diophantine 递推。
3. **可扩展**：`deltaU_history` 可设为 `nb+1` 升级为标准 GPC 多步预测（默认仍 1，现场行为不变）。
4. **死代码**：在线递推辨识默认关闭（结果未反馈回 A/B、不影响输出），保留 `use_rls_online` 开关。
5. 补边界校验（时域为正整数、柔化因子兜底、Nu≤N），命名清晰、去除 GBK 乱码注释。

### PID（`pid_calc_v2`）
1. **修复除零**：`ti<=0` 时积分项置 0 并告警，避免输出冲成 Inf/NaN；正常 `ti>0` 下与原版逐位一致。
2. **健壮性**：13 元素输入长度校验、变量命名 + 语义注释、统一列向量。
3. 控制律、死区、限幅、误差滚动逻辑与原版完全一致。

## 6. 如何接入现场（替换方式）

在 `on_timer.m` 等调用处，用重构版替换原版（**不传 opts 即与原版逐位一致**）：

```matlab
% 原版
u = gpc_clac(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd);
% 重构版（默认行为与原版一致，零风险切换）
u = gpc_clac_v2(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd);
% 若模型参数固定，可进一步缓存矩阵提速（输出仍与原版一致）：
u = gpc_clac_v2(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd, ...
                struct('use_cached', true));
```

```matlab
% 原版
pidloop(:,8) = pid_calc(pidloop(:,8)');
% 重构版（正常参数行为一致，ti=0 不再崩）
pidloop(:,8) = pid_calc_v2(pidloop(:,8)');
```

> 切换后建议先离线跑一个生产周期核对 `u` 序列与原版一致，再投自动。
