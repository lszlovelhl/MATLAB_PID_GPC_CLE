# GPC / PID 核心算法重构说明（金塬水泥202408 工程）

> 目标：在**不改变已验证现场控制行为**的前提下，按宝马工程的重构方法论，
> 把本工程核心算法从「硬编码、不可复用、有隐患」重构为「参数化、健壮、
> 可复用」的函数库。
> **范围：金塬水泥202408 工程。原版 `gpc_clac.m` / `pid_calc.m` 一个字节未改。**

---

## 1. 目录结构与产物

新增目录 `refactored/`（原文件一律未改动，便于对比回退）：

| 文件 | 说明 |
|---|---|

## 2. 默认参数值表（重构版 opts 默认值 = 本工程现场原值）

| 参数 | 字段 | 本工程原版硬编码 | 重构版默认 | 说明 |
|---|---|---|---|---|
| 预测时域 N | `opts.N` | **180**（现场整定） | **180** | 金塬现场值，与宝马 N=80 不同，重构后保持 180 |
| 控制时域 Nu | `opts.Nu` | 20 | 20 | 现场值，未改 |
| 输出/步进系数 | `opts.control_gain` | 0.7（`u=u(2)+0.7*deltaU(1)`） | 0.7 | 现场值，未改 |
| 历史 Δu 阶数 | `opts.deltaU_history` | 1（单步差分） | 1 | 默认仍为单步，保证现场行为不变 |
| 在线递推辨识 | `opts.use_rls_online` | 每周期执行（死代码） | false | 原版 THETA/P 不反馈回 A、B、不影响输出 u |
| 矩阵缓存 | `opts.use_cached` | 无（每周期重算） | false | 开启后模型不变时复用 G_/F_/H_，输出仍逐位一致 |

> 说明：`ye=abs(yr-y(3))`、自适应 `lmd=lmd1/15*ye+2/3*lmd1`、柔化轨迹
> `yd(j)=a*yd(j-1)+(1-a)*yr`、控制律 `K=(G'G+lmd*eye(Nu))\G'`、
> `deltaU=K*(Yd-Y0)` 等均为现场控制策略，**原样保留，未参数化、未改动**。

## 3. 现场参数未改动确认声明（最高优先级）

逐项确认，本次重构**未触碰**任何现场已整定的内容：

1. **控制方式 / 控制律**：GPC 预测控制、ΔU=K(Yd−Y0)、首步 Δu 步进、PID 增量式
   `du=kp[(e0−e1)+e0/ti+td(e0−2e1+e2)]` —— 与原版逐行一致。
2. **控制回路结构**：自由响应 Y0=F_·oldY+H_·oldΔu、柔化参考轨迹 Yd、
   自适应加权 λ、矩阵求解 `\` —— 结构与原版一致，仅抽出矩阵构造函数。
3. **控制策略**：死区、输出限幅 [llim,ulim]、误差历史滚动、在线辨识段的
   保留与默认关闭（关闭不影响输出）—— 策略未变。
4. **现场参数**：**N=180 是金塬现场整定后的预测时域（与宝马 N=80 的关键区别），
   重构后默认仍为 180**；Nu=20、输出系数 0.7、柔化因子 a、加权 lmd 等
   现场传入值一律未改。

## 4. 验证结果（test_verify.py，numpy 等价移植）

本机 MATLAB R2025a 许可过期，禁止运行 .m；已将**本工程原版**与**重构版**
算法逐行移植为 numpy，用相同随机输入对比，容差 1e-9。运行 `python3 test_verify.py`
结果（全部 PASS）：

| 验证项 | 组数 | 结果 | 最大误差 |
|---|---|---|---|
| GPC 默认输出一致性（N=180, Nu=20, gain=0.7） | 4 模型 × 4 输入 | 全部一致 ✓ | **3.553e-15**（< 1e-9） |
| GPC 缓存路径一致性（use_cached=true） | 3 输入 | 全部一致 ✓ | 3.553e-15 |
| PID 正常参数输出一致性 | 8 组 | 全部一致 ✓ | **0.0**（逐位一致） |
| PID `ti=0` 除零防护 | 1 组 | 输出有限且限幅内 ✓ | mv=20 ∈ [0,20] |
| GPC 时域参数化（N=60,Nu=15） | 1 组 | 可配置，不影响默认 ✓ | — |

性能对比（现场 N=180，numpy 实测，50 次平均）：

| 路径 | 单次耗时 |
|---|---|
| 原版（每周期重算 180 阶 Diophantine） | ≈ 6.06 ms/次 |
| 重构版（无缓存） | ≈ 5.96 ms/次（行为一致，去除死代码略快） |
| 预测矩阵一次性构造 | ≈ 5.77 ms（仅初始化一次） |

> 仅显著降低在线计算量。

## 5. 原版 → v2 差异摘要

### GPC（`gpc_clac.m` → `gpc_clac_v2.m` + `gpc_matrices_v2.m`）
1. **参数化**：N(=180)/Nu(=20)/control_gain(=0.7) 经 `opts` 配置，默认=现场原值。
2. **矩阵抽函数 + 可缓存**：G_/F_/H_ 仅依赖 A/B/N/Nu，抽出为 `gpc_matrices_v2.m`；
   `use_cached=true` 时用 `persistent` + 键校验（A/B/N/Nu 任一变化即重建）复用。
3. **消除死代码**：在线递推辨识默认关闭（不影响输出），保留 `use_rls_online` 开关。
4. **健壮性**：时域正整数兜底、Nu≤N、柔化因子 (0<a<1) 兜底；命名清晰、注释 UTF-8 中文。
5. 行为不变：默认 opts 下与原版逐位一致（已 numpy 验证）。

### PID（`pid_calc.m` → `pid_calc_v2.m`）
1. **修复 ti≤0 除零**：积分项置 0 并告警，输出不再 Inf/NaN；正常 ti>0 时逐位一致。
2. 输入长度校验、参数命名 + 语义注释；控制律/死区/限幅/误差滚动与原版一致。

## 6. 如何接入现场（替换方式）

在 `on_timer.m` 等调用处，用重构版替换原版（**调用签名不变**）：

```matlab
% 原版
u = gpc_clac(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd);
% 重构版（默认 N=180/Nu=20/0.7，行为与原版逐位一致）
u = gpc_clac_v2(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd);
% 若模型参数固定，可开启缓存提速（输出仍与原版一致）：
u = gpc_clac_v2(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd, ...
                struct('use_cached', true));
```

```matlab
% 原版
pidloop(:,8) = pid_calc(pidloop(:,8)');
% 重构版（正常参数行为一致，ti=0 不再崩）
pidloop(:,8) = pid_calc_v2(pidloop(:,8)');
```

> 注意：接入前建议先用现场历史 y/u 数据做一次离线回放对比（v2 默认输出应与
> 原版完全相等），确认无误后再上闭环。本工程 `N=180` 为现场值，切勿在
> 未重新整定时改为其他取值。
