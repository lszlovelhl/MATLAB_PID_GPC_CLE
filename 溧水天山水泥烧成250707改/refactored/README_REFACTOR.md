> 现场控制行为**的前提下，把本工程核心算法从「硬编码、不可复用、有隐患」重构为
> 「参数化、健壮、可复用」的 v2 版本。
>
> **本工程**：溧水天山水泥烧成250707改（以下简称“溧水工程”）。

## 4. 现场参数未改动确认声明

本重构严格遵守最高优先级约束，逐项确认如下：

- **控制律**：GPC 的 ΔU = (G'G+λI)⁻¹G'·(Yd−Y0)、λ 自适应 `lmd=lmd1/15*ye+2/3*lmd1`、
  柔化参考轨迹 `yd(j)=a*yd(j-1)+(1-a)*yr`、取第一步 `u=u(2)+0.7*Δu(1)`；
  PID 的 `du=kp*[(e0-e1)+e0/ti+td*(e0-2e1+e2)]`——**全部与原版逐式相同**。
- **回路结构**：GPC 单步取首元素、PID 13 元素向量结构与滚动逻辑——**未改动**。
- **控制策略**：死区、上下限幅、误差历史滚动、手动/自动占位——**未改动**；
  原版在线递推辨识本就不影响输出，v2 仅默认关闭（保留开关），**现场行为不变**。
- **现场参数**：N=80、Nu=20、输出系数 0.7 及所有传入模型/工况参数——**默认值即现场原值，未做任何调整**。
- **除 ti<=0 防护外**：正常参数下 v2 输出与原版逐位一致（上表误差 ≤ 3.6e-15）。

## 5. 原版 → v2 差异摘要

仅做三件允许的事，其余与原版逐行等价：

1. **参数化**：N / Nu / control_gain / deltaU_history / use_cached / use_rls_online
   经 `opts` 结构体配置，**默认值 = 现场原值**；不传 opts 时行为与原版逐位一致。
2. **ti<=0 除零修复**：仅当原版 ti=0（会产生 Inf/NaN）时触发防护（积分项置 0）；
   正常 ti>0 时与原版逐位一致。
3. **预测矩阵缓存**：`gpc_matrices_v2.m` 抽出 G_/F_/H_ 构造，仅依赖 A/B/N/Nu；
   `use_cached=true` 时用 persistent 变量 + 键（A/B/N/Nu）校验缓存复用。

附带：命名清晰化、去除乱码注释、补边界校验（时域取正整数、Nu≤N、柔化因子兜底）。
这些改动不改变正常输入下的数值结果。

## 6. 如何接入现场（替换方式，原版文件保留不动）

```matlab
% 在 on_timer.m 等调用处，用重构版替换原版（默认行为一致）：
u = gpc_clac_v2(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd);

% 若模型参数固定，可进一步开启矩阵缓存提速（输出仍与原版一致）：
u = gpc_clac_v2(A, B, P, yout1, Up1, sp, gpc_a, gpc_lmd, ...
                struct('use_cached', true));
```

```matlab
% PID：替换调用即可（正常参数行为一致，ti=0 不再崩成 Inf/NaN）
pidloop(:,8) = pid_calc_v2(pidloop(:,8)');
```
