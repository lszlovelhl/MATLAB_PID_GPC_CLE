水泥烧成系统先进过程控制 代码档案

作者在 2022–2025 年第一份工作期间，为多家水泥厂部署的烧成系统先进过程控制（APC）程序。以 MATLAB + DCS/OPC 为底座，覆盖广义预测控制（GPC）、增量式 PID、串级控制、以及自研的 CLE 趋势前馈补偿与模糊控制（FuzzyControl）。本页把全部 10 个现场工程按时间线、算法分布与架构做了结构化梳理，方便快速查阅与理解。

02核心算法

四类算法按控制任务分工：慢对象用 GPC 预测，快/回路级用增量 PID，趋势性扰动用 CLE 前馈，非线性阶段用模糊控制。

GPC · 广义预测控制

gpc_clac.m

基于 Diophantine 方程求解 + 预测矩阵（G/F/H），在线求控制增量 ΔU = K(Yd−Y0)，带柔化轨迹与自适应加权 λ。适用于分解炉温度、篦冷机等大惯性慢回路。gpc_clac1.m 为变体（N=50/Nu=15）。

PID · 增量式

pid_calc.m

13 元素参数向量的增量式 PID：Δu = kp[(e0−e1) + e0/ti + td(e0−2e1+e2)]，含死区与输出限幅。供冷却风、生料均化、氨水、风压、头煤等多个回路复用。

CLE · 趋势前馈补偿（自研）

趋势识别 + 补偿叠加

取 10s 窗口 max/min 检测连续上升/下降趋势，温度持续偏高就压控制量（−delvd）、偏低就加，按偏差分档。作为外部扰动大时的前馈补偿叠加在 GPC/PID 之上。

Fuzzy · 模糊控制

FuzzyControl.m

二维 Mamdani 模糊 PID：输入误差 Et 与误差变化率 ECt，输出控制增量 ΔF，7×7 规则表。用于点火升温等大非线性阶段。

03三大代表架构

把 10 个工程抽象为三类可复用的控制架构：分解炉串级、篦冷机多回路、CLE 趋势前馈。串级在江油拉豪最完整，CLE 在金塬最典型。

3.1 分解炉串级控制（江油拉豪 / 溧水天山）

外环 GPC 根据分解炉温度偏差算出「喂煤设定」，内环 PID 快速跟踪实际喂煤——先用预测控制把慢温度回路稳住，再用增量 PID 把执行端喂煤跟住。代码位于 on_timer.m 840–884 行。

3.2 篦冷机多回路控制（金塬 / 含山 / 江油拉豪）

篦冷机侧同时存在两条策略：一是对一段温度/料层用 GPC 或 PID 做稳态控制，二是用 CLE 做趋势前馈。江油拉豪的 control_code.m 更进一步——一段 PID 输出 upid(1)，二段、三段转速按比例联动 upid(2)=1.4·upid(1)、upid(3)=2·upid(1)。

3.3 CLE 趋势前馈补偿（金塬 428–495 行）

外部扰动大时，常规 GPC/PID 响应偏慢。CLE 取三个相邻 10s 窗口的 max/min 判断趋势：连续上升（温度偏高趋势）→ 输出减 delvd；连续下降 → 输出加 delvd；偏差越大补偿量越大，按 blj_delvd1/2/3 分档。相当于给控制器加了一个「看趋势提前动作」的前馈支路。

趋势判断补偿动作
连续上升 (mx1>mx2>mx3)输出 − (blj_vd + delvd)
连续下降 (mx1<mx2<mx3)输出 + (blj_vd + delvd)

05代码导航

各工程入口都是定时器回调 on_timer.m（部分为 onTimer_io_4duan.m），从 OPC/DCS 读数据、按周期调度各回路。核心算法函数在各工程内基本同名复用。

文件作用关键说明
on_timer.m / onTimer_io_4duan.m / on_timer1.m定时器主循环读 OPC 数据 → 解析 xml 参数 → 各回路调度（按 mod(b,周期) 触发）→ 输出到 P_write
control_code.m串级/联动控制江油拉豪、金塬：篦冷机一段 PID + 三段比例联动 + 分解炉 GPC 外环
gpc_clac.m广义预测控制核心Diophantine 求解 + 预测矩阵 + 自适应 λ；gpc_clac1.m 为参数变体（N=50/Nu=15）
pid_calc.m增量式 PID13 元素参数向量（sp/pv/mv/误差/pid/限幅/死区），多回路共用
FuzzyControl.m二维模糊 PIDMamdani：输入 Et/ECt，输出 ΔF，7×7 规则表；点火升温等非线性阶段
leastmodel.m / model_draw.m离线建模/验证递推最小二乘辨识 GPC 所需的 A/B 模型参数
on_timer.m 内 CLE 块趋势前馈补偿金塬 428–495 行；GY-750/JL-2 内联于 onTimer_io_4duan.m
refactored/各工程重构版gpc_clac_v2 / pid_calc_v2 / gpc_matrices_v2（江油拉豪另有 gpc_clac1_v2），参数化 + 修除零 + 缓存，默认参数=各现场原值，输出与原版逐位一致
