# GPC / PID 核心算法重构说明（GY-750#202230421 工程）

> 目标：在**不改动任何已验证现场控制行为**的前提下，按宝马工程的重构模式，
> 把本工程 GPC/PID 核心算法从「硬编码、不可复用、有隐患」重构为
> 「参数化、健壮、可复用」的 v2 函数库。
> **范围：GY-750#202230421（山西高义钢铁加热炉）。原版 .m 文件一个字节未改。**

## 2. 默认参数值表（opts 可配置项；默认值 = 本工程现场原值）

| opts 字段 | 默认值 | 含义 / 现场依据 |
|---|---|---|
| `N`            | **120** | 预测时域（原版 `N=120` 硬编码） |
| `Nu`           | **20**  | 控制时域（原版 `Nu=20` 硬编码） |
| `control_gain` | **1.0** | 输出系数。现场为 `u=u(2)+deltaU(1)`，**无 0.7 之类系数**，故 =1.0 |
| `deltaU_lim`   | **3000**| Δu 第一步饱和限幅绝对值（现场 `±3000`） |
| `use_cached`   | `false` | 预测矩阵缓存开关；开启后模型不变时复用 G_/F_/H_，输出仍与原版一致 |

> 其余被参数化的硬编码：无。本工程现场行为细节（索引、自适应 λ、限幅顺序）
> 一律保持原样，不参数化、不泛化。

## 3. 现场参数未改动确认声明（最高优先级）

本重构**只做了任务允许的三件事**，现场控制方式 / 回路结构 / 控制策略 / 现场参数
**一律未改动**。逐项确认：

- [x] **控制律未变**：仍是 `ΔU = K·(Yd − Y0)`，`K = (G′G + λI)⁻¹G′`，取第一步增量。
- [x] **回路结构未变**：柔化参考轨迹 `yd(j)=a·yd(j-1)+(1-a)·yr`、自由响应 `Y0=F_·oldY+H_·olddeltaU` 结构原样。
- [x] **控制策略未变**：自适应加权 `lmd = lmd1/15·ye + 2/3·lmd1` 原样保留。
- [x] **输出系数 = 1.0**：现场 `u = u(2) + deltaU(1)`，**没有 0.7 系数**；v2 默认 `control_gain=1.0`，逐位保留。
- [x] **±3000 限幅逐位保留**：`if deltaU(1)>=3000 → 3000; if deltaU(1)<=-3000 → -3000`，
      **先限幅、后计算 `u=u(2)+deltaU(1)`**，顺序与原版一致。
- [x] **无 RLS 在线辨识段**：原版 THETA/P 递推辨识段已被整段注释，本工程没有在线辨识；
      v2 **不引入任何在线辨识逻辑（连开关都不设）**。`P` 参数仅为兼容原调用接口而保留，不再被使用。
- [x] **索引细节逐行保持**：`ye=abs(yr-y(3))`、`yd(1)=y(length(y))`、`oldY=[y(3:-1:2)]'`、
      `olddeltaU=u(2)-u(1)`。
- [x] **预测矩阵构造逐行移植**：从 `Adelta=conv(A,delta)` 的 Diophantine 递推到 G_/H_/F_ 组装，
      抽为 `gpc_matrices_v2.m`，数值逻辑与原版内联段完全一致。

## 4. 验证结果（test_verify.py，numpy 等价移植）

本机 MATLAB R2025a 许可过期，**未运行任何 .m**；已将本工程原版与 v2 算法逐行
翻译为 numpy，用相同输入对比，断言默认输出逐位一致（容差 1e-9）。运行
`python3 test_verify.py` 结果（exit 0，全部 PASS）：

| 项 | 用例数 | 结果 | 最大误差 |
|---|---|---|---|
| GPC 默认输出一致性（4 组现场模型 × 5 组随机输入） | 20 | 全部一致 ✓ | **0.000e+00** |
| GPC ±3000 限幅触发（raw deltaU 真实越限） | 2 | orig=v2，限幅至 u(2)±3000 ✓ | **0.000e+00** |
| PID 正常参数输出一致性 | 10 | 全部一致 ✓ | **0.000e+00** |
| PID `ti=0` 除零防护 | 1 | 输出有限且限幅内（mv=20）✓ | — |
| GPC 时域/系数参数化（N=60,Nu=15；control_gain=0.5） | 2 | 可配置，默认不变 ✓ | — |

**限幅触发用例说明**：现场自适应 λ 会随偏差阻尼，正常工况 deltaU 远小于 3000。
测试取自由响应发散较快的模型 `A=[-1.5,1]`，令 `y(2)=±4000` 而 `ye=|yr-y(3)|=0`
（λ 不阻尼），使 raw deltaU 真实越过 ±3000：
- `y(2)=-4000` → raw≈+3866 → 限幅后 `u=5+3000=3005`；
- `y(2)=+4000` → raw≈-3677 → 限幅后 `u=5-3000=-2995`；
- orig 与 v2 输出逐位相同。

**性能**：N=120 时预测矩阵一次性构造约 4.1ms；原版每个控制周期都重算这部分，
开启 `use_cached=true` 后在线部分省去该开销（模型固定时仅首次构造）。

## 5. 原版 → v2 差异摘要

| 维度 | 原版 gpc_clac.m | v2 gpc_clac_v2.m |
|---|---|---|
| 预测/控制时域 | `N=120`、`Nu=20` 硬编码 | opts 可配，默认 120 / 20 |
| 输出系数 | `u=u(2)+deltaU(1)`（=1.0） | opts.control_gain，默认 1.0 |
| Δu 限幅 | `±3000` 硬编码 | opts.deltaU_lim，默认 3000 |
| 预测矩阵 | 函数体内联，每周期重算 | 抽为 gpc_matrices_v2，可缓存（默认关） |
| RLS 辨识 | 整段注释（死代码） | 不引入（连开关都不设） |
| ti=0 除零 | PID 原版 `1/ti` 在 ti=0 时 Inf/NaN | v2 修复：ti≤0 积分项置 0（正常参数逐位一致） |
| 其余现场行为 | — | **逐行保持，零改动** |

## 6. 接入替换说明（调用方式未变）

现场调用点在 `onTimer_io_4duan.m`（4 个 GPC 回路）：

```matlab
% 原版（行 930/947/963/979）
tempu(i) = gpc_clac(A(i,:), B(i,:), P, yy, u, yr(i), gpc_a(i), gpc_lmd(i));
% 重构版：仅改函数名，参数顺序/形态完全不变（A/B 为行向量，yy/u 为历史行向量）
tempu(i) = gpc_clac_v2(A(i,:), B(i,:), P, yy, u, yr(i), gpc_a(i), gpc_lmd(i));
% 若模型参数固定，可进一步缓存矩阵提速（输出与原版一致）：
tempu(i) = gpc_clac_v2(A(i,:), B(i,:), P, yy, u, yr(i), gpc_a(i), gpc_lmd(i), ...
                       struct('use_cached', true));
```

PID 调用点（`onTimer_io_4duan.m` 行 1435/1502/1510）：

```matlab
% 原版
pidloop(:,i) = pid_calc(pidloop(:,i)');
% 重构版（正常参数行为一致；ti=0 不再崩成 Inf/NaN）
pidloop(:,i) = pid_calc_v2(pidloop(:,i)');
```

> `pid_calc_v2` 直接复用宝马工程版本（本工程 `pid_calc.m` 与宝马逐字相同），
> 默认行为一致，仅修复 ti=0 除零。
