# PID / GPC 核心算法重构说明（JL-2#20230902 工程）

> 目标：在**完全不改变已验证现场控制行为**的前提下，把 GPC/PID 核心算法从
> 「硬编码、不可复用、有隐患」重构为「参数化、健壮、可复用」的函数库。
> 重构严格限定为三件事：硬编码参数参数化、修复 ti<=0 除零、预测矩阵可缓存。
>
> **范围：JL-2#20230902（建龙钢铁 2# 加热炉）。原版 `gpc_clac.m` / `pid_calc.m`
> 及其 `.p` 编译产物一律未改动一个字节。**

---

## 1. 目录结构与产物

新增目录 `refactored/`（仓库其他文件一律未动）：

| 文件 | 说明 |
|---|---|
| `gpc_clac_v2.m`    | 重构版 GPC，接口与原版 `gpc_clac(A,B,P,y,u,yr,a,lmd1)` 完全兼容 |
| `gpc_matrices_v2.m` | GPC 预测矩阵构造（Diophantine + G/F/H），由原版函数体内联段逐行抽离，可缓存 |

## 3. 现场行为未改动确认声明（逐项）

以下均为按现场实际工况定制的行为，重构后**默认逐位保留**，numpy 验证最大误差 0.0：

- ✅ **控制律**：`K=(G_'G_+lmd*eye(Nu))\G_'`、`deltaU=K*(Yd-Y0)` 完全一致。
- ✅ **回路结构**：柔化参考轨迹 `yd(1)=y(end); yd(j)=a*yd(j-1)+(1-a)*yr` 完全一致。
- ✅ **控制策略 / λ 自适应**：`ye=abs(yr-y(3))`、`lmd=lmd1/15*ye+2/3*lmd1` 完全一致。
- ✅ **输出系数 = 1.0**：原版末尾 `u=u(2)+deltaU(1)`，**不存在 0.7 系数**；
  v2 默认 `control_gain=1.0`，即 `u=u(2)+1.0*deltaU(1)`，逐位一致。
- ✅ **±3000 饱和限幅**：`deltaU(1)` 先被钳到 [-3000, 3000]，**之后**才计算
  `u=u(2)+deltaU(1)`；顺序与原版一致。极端输入（raw ΔU(1)≈+8097 / -47866）下，
  v2 与原版均输出 `u=u(2)±3000`，逐位一致。
- ✅ **无在线辨识段**：原版 THETA/P 递推辨识整段被注释（第 26–48 行），v2
  **不引入任何在线辨识逻辑（连开关都不提供）**，与现场一致。
- ✅ **索引细节**：`olddeltaU=u(2)-u(1)`、`oldY=[y(3:-1:2)]'`（na=1 → [y(3);y(2)]）、
  `yd(1)=y(length(y))`、`ye=abs(yr-y(3))` 全部逐行保留。
- ✅ **PID**：控制律 `du=kp*((e0-e1)+e0/ti+td*(e0-2*e1+e2))`、死区、限幅、
  误差滚动与原版逐位一致（仅修复 ti<=0 除零）。

## 5. 原版 → v2 差异摘要（仅限允许的三类改动）

1. **参数化**：`N`(120)、`Nu`(20)、`control_gain`(1.0)、`deltaU_lim`(3000)
   由函数体内硬编码改为 `opts` 结构体可配置，默认值 = 现场原值；不传 opts 时
   输出与原版逐位一致。
2. **健壮性**：PID 在 `ti<=0` 时积分项置 0（仅当原版 ti=0 触发除零时才不同；
   正常参数下逐位一致）；补时域正整数 / Nu≤N / 柔化因子兜底校验。
3. **可复用/性能**：预测矩阵 G_/F_/H_ 抽为 `gpc_matrices_v2.m`，仅依赖
   A/B/N/Nu；`use_cached=true` 时用 persistent 缓存（键校验 A/B/N/Nu），
   开启后输出仍与原版一致。
4. 注释去 GBK 乱码、命名清晰、关键现场行为加注释。
5. **未做**：未引入在线辨识、未改控制律/回路结构/控制策略/任何现场参数、
   未改 `.p` 编译产物。

## 6. 接入方式（调用处无需改动）

调用点在 `onTimer_io_4duan.m`（GPC 5 路、PID 3 处）：

```matlab
% 原版（onTimer_io_4duan.m 第 1152/1169/1185/1201/1216 行）
tempu(k) = gpc_clac(A(k,:), B(k,:), P, yy, u, yr(k), gpc_a(k), gpc_lmd(k));
% 重构版：直接换函数名即可，位置参数完全一致
tempu(k) = gpc_clac_v2(A(k,:), B(k,:), P, yy, u, yr(k), gpc_a(k), gpc_lmd(k));
% 模型参数固定时可缓存矩阵提速（可选）：
tempu(k) = gpc_clac_v2(A(k,:), B(k,:), P, yy, u, yr(k), gpc_a(k), gpc_lmd(k), ...
                       struct('use_cached', true));
```

```matlab
% 原版（onTimer_io_4duan.m 第 1829/1892/1898 行）
pidloop(:,i) = pid_calc(pidloop(:,i)');
% 重构版（正常参数行为一致，ti=0 不再冲成 Inf/NaN）
pidloop(:,i) = pid_calc_v2(pidloop(:,i)');
```
