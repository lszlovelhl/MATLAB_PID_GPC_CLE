## 3. 现场参数未改动 —— 确认声明（逐项）

**以下内容一律未改动，v2 默认行为与原版逐位一致：**

1. **控制律**：ΔU = K·(Yd−Y0)，K = (G_'G_ + λ·I)^(−1)·G_'，λ = lmd1/15·ye + 2/3·lmd1，ye = |yr − y(3)| —— 完全沿用原版。
2. **回路结构**：柔化参考轨迹 yd(1)=y(end)、yd(j)=a·yd(j−1)+(1−a)·yr；自由响应 Y0 = F_·oldY + H_·olddeltaU；索引细节 oldY=[y(3:−1:2)]'、olddeltaU=u(2)−u(1) —— 逐行保留。
3. **控制策略**：先对 deltaU(1) 做 ±3000 限幅、后计算 u = u(2) + deltaU(1)，**顺序未颠倒**；输出系数 1.0（无 0.7 系数）。
4. **现场参数**：A、B、P、柔化因子 a、控制加权基值 lmd1、N=120、Nu=20、±3000 限幅值均未改变，仅由「硬编码」变为「opts 可配置且默认取现场原值」。
5. **RLS 死代码结论**：原版 THETA/P 递推辨识段（`THETA=THETA+P*PHI*(...)`、`P=P-P*PHI*PHI'*P/(...)`）在原版中虽被执行，但其结果**从未反馈回 A、B**（反馈行 `A(na:-1:1)=-THETA(...)` 在原版中被注释），且输出 u 不依赖 THETA/P，纯属每周期无效计算。v2 因此默认关闭（`use_rls_online=false`）——**经测试，开启与关闭该开关，输出与原版完全一致**；需要真正在线辨识时可置 true（递推式与原版逐字相同）。

> 结论：不传 opts 调用 `gpc_clac_v2` / `pid_calc_v2`，控制结果与原版**逐位相同**，可直接替换。

## 5. 原版 → v2 差异摘要（仅以下三类，别无其他）

1. **参数化**：N、Nu、control_gain、deltaU_lim 由函数体内硬编码改为 opts 结构体配置，默认值=现场原值（120 / 20 / 1.0 / 3000）。
2. **健壮性修复**：PID 侧 `ti<=0` 时积分项置零并告警（正常参数下行为与原版逐位一致）；GPC 侧补基本校验（时域为正整数、Nu≤N、柔化因子兜底）。
3. **结构抽取 + 可选缓存**：预测矩阵构造抽为 `gpc_matrices_v2.m`（逐行移植原版内联逻辑）；`use_cached=true` 时按 A/B/N/Nu 做 persistent 缓存（输出仍与原版一致）。RLS 死代码段默认关闭（不影响输出）。
